album-sync

A personal photo backup script / 个人相册备份脚本

What it does

album-sync is a small script that runs on its owner's own Mac. When the Mac is idle, it uploads photos and videos from a local folder to the owner's own Google Photos library at original quality, creating one album per dated folder. It only adds items to albums it created; it never reads, changes or deletes anything else in the library.

It is not a public service. It is used by one person, for their own account.

这是什么

album-sync 是一个跑在作者自己 Mac 上的小脚本：电脑空闲时，把本地按日期分好的照片和视频，以原画质上传到作者自己的谷歌相册，每个日期文件夹建一个相册。它只往自己建的相册里添加内容，不读取、不修改、不删除相册里的其他任何东西。

这不是公开服务，只有作者本人使用。
